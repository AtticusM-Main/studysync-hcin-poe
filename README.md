# StudySync – HCIN POE Prototype

StudySync is a peer-to-peer study website for university students: form study groups, collaborate in real time (chat, shared whiteboard, shared notes), share resources and track study progress.

**Student:** Kgosi Atticus Mzuzwana · ST10495062

## Run the prototype
- **Online:** open the GitHub Pages link in the repository description (About section).
- **Locally:** download or clone the repository and open `index.html` in any modern browser. No installation or server is needed.

## Pages
| Page | Purpose |
|------|---------|
| `index.html` | Dashboard: greeting, getting-started guide, focus timer, weekly goal, deadlines |
| `groups.html` | Study groups: search with suggestions, Quick Join, create a group |
| `group.html` | Group workspace: chat with reactions, whiteboard, discussion, shared notes, calendar |
| `resources.html` | Resource library: filter, rate, report, upload |
| `profile.html` | Profile: modules, reputation, study friends |

## Repository contents
- `assets/` – stylesheet and JavaScript
- `screens/` – screenshots used as evidence in the report
- `report/` – source of the research report
- `HCIN POE - StudySync Final Report.pdf` – the updated research report

Front-end prototype built with HTML, CSS and JavaScript (no frameworks). Data is simulated in the browser.
